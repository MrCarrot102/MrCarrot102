## 🛠️ Things I built for fun

### 🎲 [AsciiCube](https://github.com/MrCarrot102/AsciiCube) &nbsp;`C++17`

A spinning 3D cube rendered as colored ASCII/Unicode art **directly in the terminal**, inspired by the legendary `donut.c`. Written from scratch in a single file with no dependencies beyond the standard library and POSIX.

- Own 3D pipeline: rotations, perspective projection, **z-buffer** and **backface culling**
- Text on the cube faces drawn with a **custom 5x7 bitmap font**, lit and rendered together with the geometry
- Live keyboard control in terminal raw mode (`termios`), alternate screen buffer like `vim` or `htop`
- 24-bit ANSI color, auto-resize to the terminal window

### 🖼️ [AsciiMore](https://github.com/MrCarrot102/AsciiMore) &nbsp;`Java`

A command-line tool that turns any image into ASCII art. Pure JDK (`javax.imageio` + `java.awt`), **zero external dependencies**.

- Luminance-based character mapping with aspect ratio correction for terminal fonts
- ANSI truecolor mode, invert mode, adjustable width
- Clear error messages instead of mysterious `null`s
